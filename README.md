# ХАБЭА зааварчилгаа уншуулах QR систем (эхний хувилбар)

Ажилтан QR уншуулна → нэвтэрнэ → заавар уншина → гарын үсэг зурна → админ тайлан харна.

## Бүтэц

| Файл | Үүрэг |
|---|---|
| `index.html`, `staff.js` | Ажилтны хуудас (QR-аар нээгдэнэ) |
| `admin.html`, `admin.js` | Админ: заавар нэмэх, QR, тайлан, CSV |
| `common.js`, `style.css` | Нийтлэг код, загвар, гарын үсгийн талбар |
| `config.js` | Supabase холболтын тохиргоо |
| `schema.sql` | Өгөгдлийн сангийн хүснэгт, хамгаалалт (RLS) |

## Тохируулах алхам

1. **Supabase төсөл үүсгэнэ:** supabase.com → New project (үнэгүй төлөв хангалттай).
2. **Өгөгдлийн сан:** SQL Editor дээр `schema.sql`-ийн бүх агуулгыг ажиллуулна.
3. **Сургууль нэмнэ:** SQL Editor дээр
   ```sql
   insert into public.schools (name) values ('Таны сургуулийн нэр') returning id, join_code;
   ```
   Гарсан `join_code` нь ажилтнуудад өгөх сургуулийн код.
4. **Түлхүүр:** Project Settings → API хэсгээс `Project URL` болон `anon public` түлхүүрийг `config.js` дотор тавина. `service_role` түлхүүрийг хэзээ ч бүү тавь.
5. **Имэйл баталгаажуулалт:** Authentication → Providers → Email хэсэгт эхний туршилтын үед "Confirm email"-ийг унтрааж болно. Бодит ашиглалтад асаасан байлгах нь аюулгүй.
6. **Админ болох:** `index.html` нээж өөрийн имэйлээр бүртгүүлээд сургуулийн кодоор нэгдэнэ. Дараа нь SQL Editor дээр:
   ```sql
   update public.profiles set role = 'admin'
   where id = (select id from auth.users where email = 'таны@имэйл');
   ```
7. **Байршуулалт:** бүх файлыг GitHub repository-д оруулж, Settings → Pages (эсвэл Netlify/Vercel)-ээр нийтэлнэ. HTTPS шаардлагатай.
8. **Ашиглах:** `admin.html` нээж нэвтэрнэ → зааварчилгаа нэмнэ → «QR» дарж хэвлэнэ. Ажилтнууд QR уншуулж бүртгүүлээд гарын үсэг зурна. «Тайлан» дээр хэн зурсан, хэн зураагүйг харна.

## Олон сургуульд зарах давхарга (schema_multi.sql, super.html)

`schema.sql`-ийн дараа `schema_multi.sql`-ийг SQL Editor дээр нэг удаа ажиллуулна. Энэ нь нэмнэ:
- Сургууль бүрт лицензийн дуусах огноо, идэвхтэй эсэх, ажилтны дээд тоо
- Лиценз дууссан сургуульд шинэ заавар нэмэх, гарын үсэг зурахыг серверээр хаана (хуучин тайлан харагдсаар байна)
- Супер админ хуудас `super.html`: сургууль нэмэх, лиценз сунгах, хэдэн ажилтан, хэдэн гарын үсэг байгааг харах, сургуулийн админ томлох

**Өөрийгөө супер админ болгох:** `index.html` дээр бүртгүүлсний дараа SQL Editor дээр
```sql
insert into public.super_admins (user_id)
select id from auth.users where email = 'таны@имэйл';
```

**Шинэ сургууль нэмэх ажлын дараалал**
1. `super.html` → «Сургууль үүсгэх» (нэр, холбоо барих, лиценз, ажилтны тоо) → сургуулийн код гарна.
2. Сургуулийн хариуцсан хүн `index.html` дээр бүртгүүлж, тэр кодоор нэгдэнэ.
3. `super.html` → «Засах» → тэр хүний имэйлийг «Админ болгох».
4. Админ өөрөө `admin.html` дээр заавар нэмж, QR хэвлэнэ. Ажилтнууд код авч нэгдэнэ.

Лицензийг гараар (төлбөр орсны дараа) сунгана. Автомат төлбөр нь дараагийн хувилбарын ажил.

## VS Code дээр туршиж үзэх

VS Code-д "Live Server" өргөтгөл суулгаад `index.html` дээр баруун товшиж "Open with Live Server" хийнэ. QR-г утсаар уншуулахын тулд нийтэд нээлттэй хаяг (Pages) хэрэгтэй.

## Хамгаалалтын тэмдэглэл

- Сургууль бүрийн өгөгдөл Row Level Security-ээр тусгаарлагдсан: ажилтан зөвхөн өөрийн сургуулийн заавар, өөрийн гарын үсгийг харна. Админ зөвхөн өөрийн сургуулийг харна.
- Ажилтны нэр, албан тушаал, гарын үсгийг серверийн trigger тогтооно, клиентээс хуурамчаар илгээх боломжгүй.
- Гарын үсгийг засах, устгах эрх ажилтанд байхгүй.
- Ажилтны нэр, гарын үсэг нь хувь хүний мэдээлэл тул хандалтыг хязгаарла.
- Электрон гарын үсгийн хуулийн хүчинтэй байдлыг сургуулийн удирдлага, хуульчаас лавла.

## Дараагийн хувилбарт нэмж болох зүйл

- Админ самбараас сургууль нэмэх, ажилтныг бөөнөөр бүртгэх
- Дуусах хугацаа хэтэрсэн ажилтанд сануулга
- Олон сургуулийн super-admin, төлбөр, лиценз
- Гарын үсэгтэй PDF тайлан
